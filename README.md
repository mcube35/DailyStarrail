# DailyStarrail

  ## 소개  
  DailyStarrail은 모바일 게임 **붕괴: 스타레일**의 일일 작업을 자동화해줍니다.
  매일매일 자동 출석체크와 자동으로 유효한 코드를 크롤링해와서 입력해줌으로써 플레이어의 귀차니즘, 깜빡증세에도 대응할 수 있습니다.

  ## 주요 기능  
  - 자동 출석체크
  - 자동 코드 크롤링 및 입력

  ## 의존성
  - Python 3.10.11
  - httpx[http2]
